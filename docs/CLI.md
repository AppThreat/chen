# CLI Usage

chen is a library; the command line entry point for the AppThreat pipeline is [atom](https://github.com/AppThreat/atom), which generates, enhances, and slices the Code Property Graph produced by chen's frontends.

- Install and usage instructions for `atom`: [AppThreat/atom](https://github.com/AppThreat/atom)
- The full `atom` option set and subcommand reference: [Lesson 16: atom CLI Commands](lessons/lesson-16-atom-cli-commands.md)

To drive chen programmatically instead, see [DSL Operations](DSL_OPERATIONS.md) and [DSL in Depth](DSL_IN_DEPTH.md).
